# Suggested automation prompts

These are reusable proposals, not active tasks. Resolve the approved private profile/context reference and source scope during setup. Choose local times, days, IANA time zone, quiet hours and a user-only destination. The agent maps [the planning template](../skills/sierra-personal-assistant/assets/automations.template.json) to the actual scheduler and verifies activation.

## Morning preparation — example: weekdays 09:30

Use $sierra-personal-assistant and my confirmed private profile at the context location agreed for this runtime. Verify profile and source access. Review only my approved sources and upcoming local workday. Identify up to three situations in which I can practice my confirmed growing edge before acting. For each, give source/date, uncertainty, relevance, action and timing. For alignment focus, look for dependencies and decisions needing input; for delegation, clarify ownership and autonomy; for strategy, clarify outcomes and assumptions. Do not contact colleagues, edit shared artifacts/events, or change my profile. Stay quiet if nothing actionable changed, where delivery suppression is supported; report material access failures accurately. Use approved private state to avoid duplicate alerts.

## End-of-day review — example: weekdays 17:00

Use $sierra-personal-assistant and my confirmed private profile at the agreed runtime context location. Verify access. Review the current local workday using only approved sources. Identify up to three unresolved commitments, useful work updates or growing-edge observations. Include evidence/date and uncertainty; check whether later context resolved each item. Suggest a next step or a draft without private feedback. Never send messages or change shared artifacts/events/profile. Avoid repeated findings and stay quiet for unchanged or non-actionable results when supported. Disclose material source failures instead of claiming a complete review.

## Weekly reflection — example: Friday 16:00

Use $sierra-personal-assistant and my confirmed private profile at the agreed runtime context location. Review the agreed local weekly interval and source scope. State coverage, evidence of progress, counterevidence and a possible missed opportunity only when supported. Distinguish facts from hypotheses. Suggest one small experiment with trigger, behavior, observable success signal and review date. Invite corrections; do not score anyone, share the reflection, contact colleagues or update my profile automatically. If evidence is sparse, say so. Deliver this explicitly requested reflection privately.

## Optional pre-sync preparation

Use $sierra-personal-assistant to prepare the specified sync using approved calendar details, previous notes and related discussions. Confirm the intended event and review window. Provide progress, open commitments, questions/decisions, a short agenda and one private growing-edge practice. Cite actual evidence and disclose missing sources. Keep a shareable agenda separate from private coaching. Do not post, change the event or edit shared notes. Check whether the scheduler supports event-based timing; otherwise offer an agreed fixed-time preparation or manual prompt, without claiming an event trigger exists.
