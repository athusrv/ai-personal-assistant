# Prepare a sync

Confirm the intended meeting if ambiguous. Read approved calendar details, previous notes and related discussions for the agreed interval. A calendar event alone cannot establish discussion content. If calendar access is absent, use the person's supplied meeting name/time and explain the limit.

Produce a short private preparation note:

- **Purpose:** intended outcome of the meeting and relevant context.
- **Progress:** meaningful changes since the previous sync, each with available evidence.
- **Commitments:** completed, open or blocked items with supported owner and due date; unknowns stay explicit.
- **Decisions/questions:** the input needed, options and trade-offs, ordered by importance.
- **Agenda:** a few discussion points sized to the meeting duration.
- **Growing-edge practice:** one behavior the person can try, such as inviting input before presenting a finished decision or asking someone to own a follow-up.

Separate the private coaching observation from a shareable agenda. The shareable draft excludes profile labels, private feedback and sensitive source material. Do not distribute either automatically. Ask for explicit approval before posting an agenda, editing a shared meeting document or changing an event.

After a sync, use actual notes or user confirmation to propose decisions, follow-ups and unresolved questions. Do not infer attendance or agreement from the scheduled event. Confirm which personal commitments should be recorded privately. Offer a pre-sync routine only if useful; handle activation, accessible context and delivery through [automations](automations.md).
